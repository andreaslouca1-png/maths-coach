Matrices and operations

A matrix is a rectangular array with order rows × columns. A linear system can be written Ax = b, where A contains coefficients, x is the unknowns column and b is the constants column.

  • Addition: matrices must have the same dimensions; add corresponding entries.
  • Scalar multiplication: multiply every entry by the scalar.
  • Matrix multiplication: AB is defined when columns of A equal rows of B. Each entry is a row-by-column dot product.
  • Identity: AI = IA = A for compatible dimensions.
  • Transpose: Aᵀ swaps rows and columns.

Simultaneous equations and solvability

If A is square and det(A) ≠ 0, A is invertible and Ax = b has a unique solution for every b. If det(A) = 0, there is no unique solution: depending on b, the system has no solution or infinitely many.

After row reduction, a row [0 … 0 | c] with c ≠ 0 is inconsistent. A consistent system with free variables has infinitely many solutions.

A zero determinant means “not unique”; check the augmented system to distinguish no solutions from infinitely many.
Gaussian elimination and row reduction

Form the augmented matrix [A | b]. Elementary row operations are: swap rows; multiply a row by a nonzero scalar; add a multiple of one row to another.

Row echelon / upper triangular form has zeros below each pivot; solve by back-substitution. Reduced row echelon form also makes each pivot 1 and clears the rest of its column, often leaving the identity matrix on the coefficient side. Pivots and zero rows reveal rank, free variables and inconsistency.

Determinants

For a 2×2 matrix, det(A) = ad − bc.

For a 3×3 matrix with rows [a,b,c], [d,e,f], [g,h,i], expansion along the first row is a(ei − fh) − b(di − fg) + c(dh − eg).

A square matrix has an inverse exactly when det(A) ≠ 0. A nonzero determinant guarantees a unique solution to Ax = b.

Inverse matrices

The inverse satisfies AA⁻¹ = A⁻¹A = I and exists only for a square matrix with nonzero determinant.

For A = [[a,b],[c,d]], A⁻¹ = 1/(ad−bc) [[d,−b],[−c,a]].

To solve Ax = b, multiply by A⁻¹: x = A⁻¹b. To find a 3×3 inverse by row reduction, reduce [A | I] to [I | A⁻¹].

2×2 inverse: swap, change signs, divide
A = [ 2  1
1  1 ]
det(A) = 2·1 − 1·1 = 1 ⟶
A⁻¹ = [ 1  −1
−1  2 ]
General rule: A⁻¹ = 1/(ad−bc) [[d, −b], [−c, a]]. For 3×3, row-reduce [A | I] until [I | A⁻¹].
LU decomposition

Factor A = LU, where L is lower triangular and U is upper triangular. In the Doolittle convention, L has 1s on its diagonal.

To solve Ax = b, solve Ly = b by forward substitution, then Ux = y by back-substitution. Row pivoting may be needed for some matrices.

Jacobi and Gauss–Seidel methods

For ∑ⱼ aᵢⱼxⱼ = bᵢ, rearrange each equation to isolate xᵢ.

Jacobi: xᵢ⁽ᵏ⁺¹⁾ = (bᵢ − ∑ⱼ≠ᵢ aᵢⱼxⱼ⁽ᵏ⁾)/aᵢᵢ. Every component in the new iterate uses values from the previous iterate.

Gauss–Seidel: use new components as soon as available: j < i uses iteration k+1; j > i uses iteration k.

Strict diagonal dominance is a sufficient convergence condition for Jacobi and Gauss–Seidel. Failing the test alone does not prove divergence.

Example system: 2x + y = 8 and x + 3y = 7, starting from (0, 0).
SOR: successive over-relaxation

SOR adjusts each Gauss–Seidel update using a relaxation parameter ω:

xᵢ⁽ᵏ⁺¹⁾ = (1−ω)xᵢ⁽ᵏ⁾ + (ω/aᵢᵢ)[bᵢ − ∑ⱼ<ᵢ aᵢⱼxⱼ⁽ᵏ⁺¹⁾ − ∑ⱼ>ᵢ aᵢⱼxⱼ⁽ᵏ⁾]

  • ω = 1 gives Gauss–Seidel.
  • 0 < ω < 1 is under-relaxation.
  • 1 < ω < 2 is over-relaxation.

Over-relaxation may reduce the iterations when Gauss–Seidel progresses slowly, but a poor ω can overshoot or diverge. A good ω depends on the matrix and is often chosen experimentally.

The matrix formula depends on the sign convention used when splitting A into D, L and U, so this component-wise form keeps the signs explicit.

Number sets: natural, integer, rational, real and complex

A useful nesting is N ⊂ Z ⊂ Q ⊂ R ⊂ C. Here N = {1, 2, 3, …} (some courses include 0 in N), Z contains integers, Q contains ratios of integers, R contains real numbers, and C contains complex numbers.

  • Irrational real: in R but not Q, for example √2.
  • Algebraic: a root of a nonzero polynomial with rational coefficients; √2 is algebraic.
  • Transcendental: not a root of any nonzero polynomial with rational coefficients; π and e are examples.
Number-system nesting
N⊂Z⊂Q⊂R⊂C
Each set contains the sets to its left. Irrational numbers belong to R\Q; non-real complex numbers lie in C\R.
Complex numbers and square roots of negative numbers

Extend the real numbers by defining i² = −1. A complex number is z = x + iy, where x and y are real. The equation x² + 5 = 0 has no real solution, but in C its roots are z = ±i√5.

For z = x + iy, Re(z) = x and Im(z) = y. The imaginary part is a real number (the coefficient of i).

Addition, subtraction, multiplication and division

Add or subtract corresponding real and imaginary parts. For multiplication, expand as usual, then replace i² with −1. For division, multiply top and bottom by the conjugate of the denominator.

Complex conjugate and modulus

If z = x + iy, then z̄ = x − iy. The conjugate pair satisfies z + z̄ = 2 Re(z) and z − z̄ = 2i Im(z).

The modulus is the distance from the origin: |z| = √(x² + y²). Also z z̄ = x² + y² = |z|², a nonnegative real number.

Conjugate product gives the squared distance
z = 3 + 4i×z̄ = 3 − 4i=9 + 16 = 25 = |z|²
Here |z| = 5. Geometrically, z and z̄ are mirror points and each is 5 units from the origin.

Useful identities: overline(z+w) = z̄+w̄; overline(zw) = z̄w̄; |zw| = |z||w|; and, for w ≠ 0, |z/w| = |z|/|w|. Modulus is not generally additive; instead, |z+w| ≤ |z|+|w|.

Fundamental Theorem of Algebra

A polynomial of degree n has exactly n roots in C, counting repeated roots with multiplicity. A monic polynomial factors as p(z) = (z−z₁)(z−z₂)…(z−zₙ).

Example: z² + 7 = 0
z² = −7⟶z = ±i√7⟶z² + 7 = (z − i√7)(z + i√7)
There are two complex roots, as expected for a degree-two polynomial.
